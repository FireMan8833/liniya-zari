# Линия Зари

Сюжетный 2D-платформер (Canvas 2D + WebGL2). Часть I: четыре главы.

**Играть в браузере:** https://fireman8833.github.io/liniya-zari/

Управление: A/D или ←/→ — бег, Пробел/W/↑ — прыжок, E — Клюв (держать), Shift — рывок, Q — обогрев/плащ, S/↓ — тихий шаг, Esc — пауза.
Сохранения и настройки хранятся в браузере. Лучше всего работает в Chrome/Edge. На слабых ПК: Настройки → Качество графики → «Минимальное».

Большие ассеты разбиты на части в `assets/` (ограничение загрузки), собираются при запуске.
