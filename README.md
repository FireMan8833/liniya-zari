# Линия Зари

Сюжетный 2D-платформер. Восемь глав о путевой обходчице Ирме Кесс, городе Орсо и ремонте Кольцевого пути. Версия 0.9.0 — «Ремонтная смена».

Играть: https://fireman8833.github.io/liniya-zari/

A/D или ←/→ — движение; Пробел — прыжок; E — Клюв, кнопки и ремонт; Shift — рывок; Q — обогрев/отражатель; R — тормоз механизмов; Tab — журнал задачи; T (1 с) — к контрольной точке; Esc — пауза.

Настройки, контрольные точки и решения головоломок хранятся в браузере. Chrome/Edge, клавиатура или геймпад. Мобильный журнал адаптивен, но сенсорное управление платформером не добавлено.

Речь предварительно синтезирована через Gemini, музыка и эффекты сохранены. Во время игры Gemini API не вызывается. Все необходимые ресурсы находятся в репозитории; ключи API в сборку не входят.
